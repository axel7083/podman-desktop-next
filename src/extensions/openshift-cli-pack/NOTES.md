# redhat.openshift-cli-pack (proposed)

**Real objects / API.** oc, rosa, ocm, tkn, roxctl, virtctl, kn, openshift-install, opm, operator-sdk, oc-mirror, shp (Oct 2026 version estimates). Installed versions live in world.settings['cli.<ext>.<name>'] like core CLI Tools.

**Placement.** Featured tools in Settings › CLI Tools (P17), full pack + version-skew banner in Settings › OpenShift CLI (no TOOLS nav item, scaling).

**Journeys.** Install recommended (parallel tasks); Update oc from the skew banner or from OCM connect.
